# ONG Esperança — Experiência Prática III

Projeto acadêmico de Desenvolvimento Front-end.

## Estrutura

- `html/index.html` — estrutura da página.
- `css/style.css` — estilos e responsividade.
- `js/script.js` — inicialização geral.
- `js/templates.js` — templates e criação dinâmica dos cards.
- `js/storage.js` — localStorage.
- `js/eventos.js` — eventos, máscaras, validação e modal.
- `js/router.js` — navegação SPA baseada em hash.
- `imagens/` — imagens locais do projeto, se necessário.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- DOM
- Eventos
- localStorage
- SPA baseada em hash
- Modularização com ES Modules

## Testes sugeridos

1. Abrir `html/index.html`.
2. Testar os links do menu.
3. Testar o menu em tela pequena.
4. Conferir se os cards aparecem dinamicamente.
5. Tentar enviar o formulário vazio.
6. Preencher o formulário corretamente.
7. Conferir a mensagem de sucesso.
8. Abrir DevTools > Application/Armazenamento > Local Storage.
9. Verificar a chave `ongEsperanca_mensagens`.
10. Testar o modal de doação.
11. Verificar a chave `ongEsperanca_ultimaDoacao`.

Observação: o armazenamento local é apenas para demonstração acadêmica. Não utilizar este projeto para armazenar dados pessoais reais em produção.
